# SpaceWise

SpaceWise is a modern, sleek storage management application for Android, built with web technologies using Capacitor. It helps users analyze their storage, find duplicate files, manage installed applications, and free up space with intelligent insights.

## Tech Stack

*   **Framework:** React 19
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS (v4)
*   **State Management:** Zustand
*   **Animations:** Framer Motion
*   **Icons:** Lucide React
*   **Charts:** Recharts
*   **Mobile Container:** Capacitor (Android)

## Features

*   **Dashboard/Home:** Overview of storage usage and quick cleanup suggestions.
*   **App Manager:** View and manage installed applications.
*   **File Explorer:** Navigate and manage files categorized by type.
*   **Duplicate Finder:** Identify and remove duplicate files to save space.
*   **Storage Insights:** Detailed charts and breakdown of what is taking up space.
*   **Dark Mode:** Full support for system-level dark mode and manual overrides.

## Getting Started

### Prerequisites

*   Node.js (v18+)
*   npm or yarn
*   Android Studio (for Android deployment)

### Installation

1.  Clone the repository or navigate to the project directory.
2.  Install dependencies:

    ```bash
    npm install
    ```

### Development

Run the development server locally:

```bash
npm run dev
```

### Build and Deploy to Android

1.  Build the web assets:

    ```bash
    npm run build
    ```

2.  Sync the built assets with the Capacitor Android project:

    ```bash
    npx cap sync android
    ```

3.  Open the project in Android Studio to build and run on an emulator or physical device:

    ```bash
    npx cap open android
    ```

## Project Structure

*   `src/`: Contains the React source code.
    *   `components/`: Reusable UI components (BottomNav, Sheet, etc.).
    *   `screens/`: Main application views (HomeScreen, AppsScreen, FilesScreen, etc.).
    *   `store/`: Zustand state management.
*   `android/`: The native Android project generated by Capacitor.
*   `vite.config.ts`: Vite configuration.
*   `capacitor.config.ts`: Capacitor configuration.
